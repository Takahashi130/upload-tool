upload-tool ／ 制定：2026年9月29日

このツールについて

upload-tool は、運営者本人が管理する YouTube チャンネルへ動画を投稿するための個人用ツールです。利用者は運営者本人だけで、一般の方には提供していません。

利用する Google のデータ

  • youtube.upload：運営者本人のチャンネルへの動画のアップロード、サムネイルの設定
  • youtube.readonly：投稿先チャンネルの確認、投稿済み動画の状態の確認（二重投稿の防止）

これ以外の Google アカウントの情報は取得しません。

保存と共有

  • 認証情報は、運営者本人のコンピュータにだけ保存します。サーバーは持ちません。
  • 取得したデータを第三者に提供・販売しません。広告や分析には使いません。
  • Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

English summary: upload-tool is a personal tool used only by its owner. It uses the YouTube Data API scopes youtube.upload and youtube.readonly solely to upload videos to, and check the status of, the owner's own channels. Credentials are stored only on the owner's computer. No data is shared, sold, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
